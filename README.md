# memomate

메모 · 할 일 · 캘린더를 하나로 묶은 알림장 웹 앱입니다. (1단계: AI 없음)

## 실행

Python이 설치된 Windows에서 `start.bat`을 더블클릭하면 `http://localhost:5000/memomate.html`이 열립니다.

다른 환경에서는 이 폴더에서 아래 명령을 실행한 뒤 같은 주소로 접속하세요.

```
python -m http.server 5000 --bind 127.0.0.1
```

## 기능

- 메모: 자동 저장, 검색, 태그/폴더, 고정, 색상, 휴지통, `- [ ]` 체크박스의 할 일 연동
- 할 일: 마감일, 우선순위, 필터, 하위 할 일, 반복
- 캘린더: 월간/주간, 일정, 한국 공휴일(2025~2027)
- 오늘 화면, 통합 검색, JSON 백업, 다크 모드, 모바일 대응

## 참고

- 데이터는 브라우저 localStorage에만 저장됩니다. 설정에서 JSON으로 백업하세요.
- 공휴일 데이터는 직접 입력한 정적 데이터이며 법령 원문과 대조하지 않았습니다.
