# memomate

메모, 할 일, 캘린더, 알림을 하나로 묶은 알림장 웹 앱입니다. 3단계까지 구현했고, AI 기능은 아직 없습니다. 기획 문서는 [memomate_PRD.md](memomate_PRD.md)에 있습니다.

- 배포 주소: https://memomate-local.vercel.app

## 실행

Python이 설치된 Windows에서는 이 폴더의 `start.bat`을 더블클릭하세요. `http://localhost:5000/memomate.html`이 열립니다.

다른 환경에서는 이 폴더에서 아래 명령을 실행한 뒤 같은 주소로 접속하세요.

```
python -m http.server 5000 --bind 127.0.0.1
```

## 기능

**1단계: 기본 기능**
- 메모: 자동 저장, 검색, 태그·폴더, 고정, 색상, 휴지통, `- [ ]` 체크박스를 할 일로 연동
- 할 일: 마감일, 우선순위, 필터, 하위 할 일, 반복
- 캘린더: 월간·주간 보기, 일정, 한국 공휴일(2025~2027)
- 오늘 화면, 통합 검색, JSON 백업, 다크 모드, 모바일 대응

**2단계: 알림**
- 할 일·일정·메모 알림: 항목 하나에 최대 3개, 정각부터 1일 전까지 고르거나 직접 입력
- 알림 카드: 완료, 10분 뒤, 내일로, 열기, 닫기
- 알림함, 놓친 알림, 아침 브리핑, 방해 금지, 브라우저 알림, 알림음

**3단계: 편의 기능**
- 자연어 빠른 입력(`Ctrl+K` 또는 `/`): 예를 들어 "내일 오후 3시 팀 회의 30분 전 알림 #업무"
- 단축키: `?`를 누르면 목록이 나옵니다.
- 캘린더 드래그 이동과 실행 취소
- 주간 회고, 미룬 일 모아보기, 할 일 직접 정렬

## 참고

- **데이터 저장:** 데이터는 브라우저 localStorage에만 저장됩니다. 주소(사이트)마다 따로 저장되므로, 로컬과 배포 주소는 데이터를 공유하지 않습니다. 옮기려면 설정의 JSON 백업과 복원을 쓰세요.
- **알림이 울리는 조건:** 정시 알림은 앱 탭이 열려 있을 때만 울립니다. 탭을 닫아 둔 동안 지난 알림은 다음에 열 때 "놓친 알림"으로 보여 줍니다.
- **버전을 섞어 열지 마세요:** 같은 주소에서 예전 버전의 memomate 탭을 함께 열어 두면, 그 탭이 오래된 데이터로 새 데이터를 덮어쓸 수 있습니다.
- **공휴일 데이터:** 직접 입력한 정적 데이터이며, 법령 원문과 대조하지 않았습니다.
